# pi-pocket-view

A custom PyQt6 desktop application designed to interact with a Raspberry Pi 5 operating in USB OTG Gadget mode.

### Features
* Low-Latency Video Feed: View the Pi's display output directly inside a native desktop window.
* Embedded Terminal: Integrated ttyd web terminal to manage your Pi without external SSH clients.
* Cross-Platform: Runs natively on Arch Linux (ELF) and Windows 11 (.exe).
* Plug & Play: Designed to launch automatically when the USB-C cable is connected.

### Built With
* Python 3 & PyQt6
* QtWebEngine (Chromium)
* Arch Linux ARM (Raspberry Pi 5)
